## 📌 Overview

**SkillSphere AI** is an AI-powered skill recommendation and career guidance platform built using **React, Node.js, Express, and Neo4j Graph Database**. The platform connects users, skills, jobs, companies, and courses to provide intelligent career recommendations and visualize relationships using graph-based data.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Abrar-Kaif1741/SkillSphere-AI.git
```

## Install Backend

```bash
cd server
npm install
npm start
```

## Install Frontend

```bash
cd client
npm install
npm run dev
```

---

# 🔐 Environment Variables

## Backend (.env)

```env
DB_URI=YOUR_NEO4J_URI
DB_USER=YOUR_DATABASE_USERNAME
DB_PASSWORD=YOUR_DATABASE_PASSWORD
PORT=5000
```

## Frontend (.env)

```env
VITE_API_URL=https://YOUR-RENDER-BACKEND-URL.onrender.com/api
```
